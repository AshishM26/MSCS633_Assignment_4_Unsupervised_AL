# Dataset

Obtain the [Credit Card Fraud Detection dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) from Kaggle and place `creditcard.csv` in this directory. It is excluded from Git; the program does not download it. The expected schema is `Time`, `V1`–`V28`, `Amount`, and `Class` (31 columns), with 284,807 transactions including 492 frauds. `Class` is an evaluation label, never a model feature.
